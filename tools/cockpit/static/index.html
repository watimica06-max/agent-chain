Ajouter une application

La racine d'un dépôt git. L'ajouter ne touche à aucun de ses fichiers : la liste du cockpit change, et sa configuration git reçoit core.longpaths=true. La chaîne s'y installe ensuite depuis sa carte.

Si la fenêtre de choix ne s'ouvre pas, collez le chemin dans le champ.

Ajouter depuis GitHub

Une application qui est déjà sur GitHub — créée ou travaillée sur l'autre ordinateur : elle est clonée ici, puis ajoutée à la liste comme « Ajouter » le fait. Sans identifiant GitHub sur cet ordinateur, le clone d'un dépôt privé est refusé, et c'est dit — jamais demandé.

      ≈ : ce qu'un run a pris aux limites, l'écart entre la mesure de son début et celle de sa fin. Les limites comptent tout ce que le compte a utilisé entre-temps, pas ce run seul, et se lisent au pour cent. « inconnu » : le chiffre n'est pas dans la base — il n'entre dans aucune somme, et la somme le dit.

      Thème
          
      
            
            
            
          
      
        
      
        
      Auto suit le réglage de l'ordinateur. Le choix est gardé par ce navigateur, comme les notifications et le menu.
      
      
      
      
      
        
      Mode de permission
      
        
      Ce que Claude fait sans vous demander pendant une commande, et ce qui arrive en bandeau pour que vous l'autorisiez.
      
        
      
        
      
      
      
      
      
        
      Notifications
      
        
      Quand l'onglet du cockpit n'est pas devant : le navigateur montre une notification ; un clic ramène l'onglet sur l'écran concerné. Devant, la page le montre déjà.
      
        
      
        
        
      Sur ce téléphone
      
        
      
      
      
      
      
      
        
      Accès depuis le téléphone
      
        
      Tailscale relie cet ordinateur et le téléphone en réseau privé ; tailscale serve y présente le cockpit en HTTPS, à l'adresse de l'ordinateur. Rien n'est ouvert sur internet. Le téléphone donne le code d'accès une fois ; ce navigateur-ci n'en a jamais besoin. Les étapes : LISEZMOI.md, « Téléphone ».
      
        
      
      
      
      
      
        
      Dossiers ignorés
      
        
      Les dossiers de docs/features/ que rien ne doit montrer — ceux d'une ancienne chaîne : ni la liste des features, ni « Correction », ni les Statistiques, ni le Code.
      
        
      
      
      
      
      
      
        
      État de l'ordinateur
      
        
      Tout ce qui doit être présent et à jour pour que la chaîne tourne bien sur cet ordinateur. Chaque ligne dit son état, sa règle — se répare seul, signale, ou bloque — et quand elle a été vérifiée ; sa réparation se fait d'ici, d'un clic, jamais dans PowerShell. Vérifié au démarrage du cockpit, à l'ouverture de cet écran, après chaque réparation, et avant un lancement pour ce qui le bloque.
      
        
      
          
      
        
      
          
          Rapide : les étapes et les licences acceptées d'avance, nommées avant le départ. Pas à pas : une carte par étape et par licence, en entier.
      
        
      
        
      
        
      
        
      Le détail des outils de l'application ouverte
          
      
      
      
      
      
        
      Version du cockpit
      
        
      Le cockpit et la chaîne viennent du dépôt agent-chain de cet ordinateur. « Mettre à jour le cockpit » y récupère la dernière version depuis GitHub, réinstalle ses dépendances Python si elles ont changé, puis redémarre le cockpit : la page se recharge d'elle-même. Refusé pendant qu'une commande tourne.
      
        
      
        
        
        
        
        
        
      
        
      
        
        
        Arrêter le cockpit
        
        
        Fermer l'onglet ou le navigateur n'arrête rien : un run continue, et la page rouverte le reprend où il en est. Ceci arrête le serveur du cockpit lui-même ; le raccourci du bureau le relance.
