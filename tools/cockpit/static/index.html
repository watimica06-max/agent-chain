        Chaîne
        
        
        Les agents, les commandes, les scripts et les grilles de l'application viennent du dépôt de la chaîne, à son dernier commit. On ne les change que là-bas ; ici, on les installe. Les fichiers propres à l'application — son /deploie — ne sont jamais touchés.

        Commandes

        Notifications
        
        
        Quand l'onglet du cockpit n'est pas devant : le navigateur montre une notification ; un clic ramène l'onglet sur l'écran concerné. Devant, la page le montre déjà.
